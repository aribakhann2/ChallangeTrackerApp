# 📅 Challenge Tracker App

Challenge Tracker App is a **personal goal & habit tracking** mobile application built in **Android Studio (Kotlin)**.  
It allows users to create challenges, log daily progress, and visualize their journey with a progress bar.  
The app uses **Room SQL** for local storage and **Firebase** for cloud sync, ensuring that progress is always available across devices.

## ✨ Features

- **User Authentication**  
  - Sign up and login using Firebase Authentication.

- **Create Challenges**  
  - Set challenge name, description, and target duration.

- **Daily Progress Logging**  
  - Log your progress daily for each challenge.

- **Progress Visualization**  
  - Interactive progress bar showing completion percentage.

- **Local & Cloud Storage**  
  - **Room SQL** for offline usage.  
  - **Firebase** for backup and sync.

- **Navigation Drawer**  
  - Easy navigation between challenges, progress, and settings.

---

## 🛠 Tech Stack

- **Kotlin** – Core Android app development.
- **Room SQL** – Local database for offline data storage.
- **Firebase** – Authentication & real-time cloud backup.
- **Android Jetpack Components** – ViewModel, LiveData, Navigation.
